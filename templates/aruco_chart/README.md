# ArUco精度検証タブ — グラフのテンプレート

「Excel出力（軸ごとシート）」が各シートに挿し込むグラフの定義です。

## なぜこの形なのか

openpyxl でグラフを組み立て直すと、線幅・マーカー・配色・レイアウトが
元の見た目から変わってしまいます（実際に一度それで作り直して見た目が変わりました）。

そこで **Excel で仕上げたグラフの XML をそのままコピー**し、
参照するシート名と行範囲だけを書き換える方式にしています。
書式は 1 バイトも変更しません。

## ファイル

| ファイル | 中身 |
|---|---|
| `chart1.xml` | グラフ「RGB」（計測 = 列 AK） |
| `chart2.xml` | グラフ「depth_corner」（計測 = 列 AL） |
| `chart3.xml` | グラフ「fusion」（計測 = 列 AM） |
| `style.xml` / `colors.xml` | 3つのグラフで共有するスタイル |
| `drawing.xml` | シート上の配置（3つ分の枠） |

いずれも `<c:numCache>` は除いてあります（Excel がシートから計算し直すので不要。
残すと 209KB → 37KB の差になり、古い値が焼き付きます）。

## 参照している列

出力シートの列構成に合わせてあります。**列を増減するとズレます。**

| 列 | 内容 |
|---|---|
| AI | 【横軸】経過時間_s |
| AJ | 【縦軸】理想_ロボット |
| AK | 【縦軸】計測_rgb |
| AL | 【縦軸】計測_depth_corners |
| AM | 【縦軸】計測_fusion |

行範囲は出力のたびに、その軸の等速区間へ自動で書き換わります。

## 見た目を変えたいとき

1. 出力した .xlsx を Excel で開いてグラフを好きなように整える
2. その .xlsx を zip として開き、`xl/charts/chart1〜3.xml` を取り出す
3. `<c:numCache>` と `<c:strCache>` を取り除いて、このフォルダの同名ファイルへ上書き

軸の最大値・最小値もこの XML に入っているので、テンプレート側で決めた値が
毎回使われます（自動調整はしていません）。試験ごとに変えたい場合は
Excel 上で個別に調整してください。

## 見本の Excel から取り込む方式（2026-09-04 追加・こちらが本命）

タブの「④ Excel出力に使うグラフのテンプレート」→「見本のExcelからグラフを取り込む」で、
**自分で体裁を整えたグラフを雛形にできます。** 取り込んだものは
`templates/aruco_chart_user/` に入り、以降の出力ではそちらが優先されます。

* 見本は **グラフ1つでOK**。出力時に rgb / depth_corners / fusion の3つに増やします
  （縦軸の「計測」だけ差し替え、グラフのタイトルを手法名にします）
* 横軸が「経過時間」でも「理想」でも構いません。列の**見出しに含まれる語**
  （`経過時間` / `理想` / `計測`）で役割を判定するので、
  理想 × 計測 の散布図に 理想 × 理想 の y=x 線を重ねた見本もそのまま扱えます
* グラフが複数入ったファイル（＝これまでの出力そのもの）を渡すと、どれを使うか選べます
* 判定できない列があれば取り込み時に聞きます
* 「既定に戻す」でこのフォルダ（`aruco_chart/`）の3枚組に戻ります

このフォルダの chart1〜3.xml は**取り込みが無いときのフォールバック**です。
